# Tamil Nadu, Covered — source

`../index.html` is the ready-to-open standalone microsite (just double-click it).

To edit the campaign and rebuild:
1. Edit numbers/copy in `src/data.js` (and `src/App.jsx` for layout/behaviour).
2. `npm install`
3. `npm run build` — produces `build.js`.
4. Paste `build.js` between the `<script>` / `</script>` tags at the end of `../index.html` (replacing the old bundle), or ask Claude to rebuild it for you.
